# Naming Review

Reviewed on August 13, 2026.

The exact name `StayLoaded` had no result in searches of Modrinth projects, GitHub repository names, or Hangar projects. General web search produced no relevant Minecraft result. CurseForge and Spigot blocked or limited unauthenticated search, so these findings are preliminary availability research rather than trademark clearance or a guarantee of marketplace approval.

`Unplugged AFK` is already used by an active Fabric project on Modrinth and GitHub, and by a NeoForge port on CurseForge. StayLoaded therefore uses distinct branding, assets, package names, repository identity, and marketplace copy.
